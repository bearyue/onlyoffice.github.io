# Changelog

## 1.5.0

- Add an icon-only floating magnifier for a single selected image.
- Hide the floating entry when the image is deselected or the preview is opened.
- Retain the image context-menu entry and existing image navigation.
- Explicitly register and handle floating-button click events.

## 1.4.1

- Replace the current image selection when navigating instead of adding the target image to the existing selection.

## 1.4.0

- Add previous/next image arrows and Left/Right keyboard navigation.
- Disable navigation controls at the first and last image.

## 1.3.1

- Use icon-only maximize/restore controls with light and dark theme icons.

## 1.3.0

- Add preview window size controls to the title bar.

## 1.2.0

- Enable window-border resizing and automatic image fitting in fit-to-window mode.

## 1.1.2

- Register the context-menu click event so the preview action reaches the plugin.

## 1.1.1

- Remove an empty submenu from the image preview context-menu item.

## 1.1.0

- Add automatic startup and the image context-menu entry.

## 1.0.0

- Initial image preview window with wheel zoom, panning, fit-to-window, and 100% view.
